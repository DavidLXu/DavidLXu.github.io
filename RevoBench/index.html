项目介绍

RevoBench 探索用 Agent 完成灵巧操作 benchmark 的构建与验证。我们基于高保真的数字资产搭建仿真环境，由 Agent 编写任务、生成示例轨迹，并根据执行结果检查和修改实现。

示例轨迹用于验证任务能否完成，也用于发现问题。物体到达目标位置时，手臂仍可能出现不自然的绕行，或依靠拇指背部抓持。我们结合执行记录检查姿态、运动连续性与接触方式，并要求机器人从默认姿态出发，完成后回到默认姿态。

后续将由 Agent 参与构建评测程序，在固定的任务条件下比较不同 agent-based policy。环境、示例轨迹和评测接口将整理为统一的任务包，方便新的 Agent 独立运行和复现结果。
